Agent Skills are reusable instruction bundles for coding agents. They help standardize how an agent handles specific implementation patterns, which is especially useful when you want consistent behavior across multiple repos or teams.

## What a skill is

A skill usually includes:

- a focused workflow
- implementation guidelines
- patterns to follow
- examples of the intended output

## Good use cases

- image generation workflows
- UI implementation standards
- API integration rules
- code review or debugging checklists

## How teams use them

<Steps>
<Step>
### Define the workflow

Pick one narrow job the agent should perform consistently.

</Step>

<Step>
### Package the instructions

Write the rules, examples, and expected behavior in a reusable format.

</Step>

<Step>
### Reuse across projects

Load the same skill into multiple agent environments so teams get more consistent results.

</Step>
</Steps>

## Why this matters

Without reusable skills, agent output tends to drift between projects. Skills make it easier to preserve implementation standards, reduce onboarding time, and make agent behavior easier to reason about.
