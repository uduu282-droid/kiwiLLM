# KiwiLLM CLI

KiwiLLM does not currently ship a public standalone CLI package in this repository.

If you are looking for a command-line way to work with KiwiLLM today, the practical options are:

- call the hosted API directly
- use one of the editor or agent integrations from the other guides
- run the repository locally if you are contributing to KiwiLLM development

## What to use right now

### API-first workflows

Use the OpenAI-compatible API directly:

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5",
    "messages": [
      {
        "role": "user",
        "content": "Hello from the command line."
      }
    ]
  }'
```

### Local development

If you want a local platform workflow, clone the repository and run the monorepo directly:

```bash
git clone https://github.com/uduu282-droid/kiwiLLM.git
cd kiwiLLM
pnpm install
docker compose up -d
pnpm setup
pnpm dev
```

That gives you the local apps documented throughout this site, including:

- UI
- API
- Gateway
- Docs

## Why this page exists

Earlier docs referenced an older CLI concept that is not currently represented as a shipped package in this repository. This page is here to make the current state explicit so you do not waste time trying to install a package that is not part of the active codebase.
