n8n works well with KiwiLLM because KiwiLLM exposes OpenAI-compatible endpoints that can be used from the OpenAI credential and model nodes.

![n8n workflow with KiwiLLM](/guides/n8n/overview.png)

## Prerequisites

- a KiwiLLM API key
- an n8n instance

## Setup

<Steps>
<Step>
### Create OpenAI credentials in n8n

Use:

- **API Key**: your KiwiLLM API key
- **Base URL**: `https://api.kiwillm.in/v1`
- **Organization ID**: leave blank unless your setup specifically requires it

</Step>

<Step>
### Attach the credential to your AI node

Use the OpenAI-compatible model node or AI agent flow in n8n and attach the credential you just created.

</Step>

<Step>
### Choose a model

Pick a KiwiLLM model ID, such as:

- `gpt-5`
- `gpt-4o`
- `claude-sonnet-4-5`
- `gemini-2.5-pro`

</Step>

<Step>
### Test the workflow

Run a simple prompt through the workflow to confirm requests succeed.

</Step>
</Steps>

## Important note

Some n8n configurations assume OpenAI’s newer Responses API. If your workflow fails, switch back to chat-completions-style usage and use the standard OpenAI-compatible path through KiwiLLM.

<Callout type="warning">
	Start with a plain chat completion workflow first. Once that works, layer in
	tools, structured outputs, or multi-step agent behavior.
</Callout>
