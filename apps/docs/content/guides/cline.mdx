[Cline](https://cline.bot) supports OpenAI-compatible providers, which makes KiwiLLM a straightforward drop-in option for coding workflows in VS Code.

## Prerequisites

- a KiwiLLM API key
- VS Code or a compatible editor
- the Cline extension installed

## Setup

<Steps>
<Step>
### Install the extension

Install the Cline extension from the VS Code marketplace.

</Step>

<Step>
### Open provider settings

In the Cline sidebar, open the settings panel and choose **OpenAI Compatible** as the provider type.

</Step>

<Step>
### Enter the KiwiLLM connection values

Use:

- **Base URL**: `https://api.kiwillm.in/v1`
- **API Key**: your KiwiLLM API key
- **Model ID**: any supported model, such as `gpt-5`, `claude-sonnet-4-5`, or `gemini-2.5-pro`

</Step>

<Step>
### Test a request

Ask Cline to create or edit a small file. If the request succeeds, the integration is working.

</Step>
</Steps>

## Model tips

- use direct model IDs like `gpt-5` for normal routing
- use provider-prefixed IDs like `openai/gpt-5` when you want a fixed upstream
- use the [Models page](https://kiwillm.in/models) to browse available options

## Why use KiwiLLM with Cline

- one API key across multiple providers
- usage and cost visibility in the dashboard
- unified OpenAI-compatible setup
- optional routing and fallback behavior

<Callout type="info">
	If you want to compare models for coding tasks, start with one strong model
	and one cheaper fallback, then evaluate based on latency, quality, and cost.
</Callout>
