Azure can be used as a provider inside KiwiLLM by adding your Azure resource details and API key in the Provider Keys section.

<Callout type="info">
	This integration is focused on Azure OpenAI-style deployments.
</Callout>

## Prerequisites

- an Azure account with an active subscription
- an Azure OpenAI resource
- at least one deployed model
- a KiwiLLM account or self-hosted KiwiLLM deployment

## Setup

<Steps>
<Step>
### Create the Azure resource

In the Azure portal:

1. create an Azure OpenAI resource
2. choose the right region
3. wait for deployment to complete

</Step>

<Step>
### Deploy models in Azure

Create the model deployments you want KiwiLLM to call. Keep the deployment names aligned with the model identifiers you expect to use.

</Step>

<Step>
### Copy the API key and resource details

From **Keys and Endpoint**, collect:

- your API key
- your resource name or endpoint

</Step>

<Step>
### Add the Azure provider key in KiwiLLM

In KiwiLLM:

1. open **Provider Keys**
2. choose **Azure**
3. enter the API key
4. enter the resource name
5. set a validation model that already exists in your Azure deployment

</Step>

<Step>
### Test the connection

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "azure/gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "Hello from Azure."
      }
    ]
  }'
```

</Step>
</Steps>

## Notes

- only models deployed in your Azure resource will work
- quotas and rate limits are still controlled by Azure
- region availability differs by model family

Browse models on the [Models page](https://kiwillm.in/models?provider=azure).
