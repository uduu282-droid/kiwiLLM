AWS Bedrock can be connected to KiwiLLM through provider keys so your hosted KiwiLLM project can route requests through your Bedrock account.

## Prerequisites

- an AWS account with Bedrock access
- model access enabled for the models you want to use
- a KiwiLLM account or self-hosted KiwiLLM deployment

## Setup

<Steps>
<Step>
### Enable Bedrock model access

In AWS:

1. open Bedrock
2. go to **Model access**
3. enable the models you plan to use

</Step>

<Step>
### Create or collect the Bedrock credentials you need

Use the Bedrock credentials and region setup that matches your AWS configuration.

</Step>

<Step>
### Add the provider key in KiwiLLM

In the KiwiLLM dashboard:

1. open **Provider Keys**
2. choose **AWS Bedrock**
3. paste the Bedrock credential details
4. select the correct region or region prefix

</Step>

<Step>
### Test a request

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aws-bedrock/claude-3-5-sonnet",
    "messages": [
      {
        "role": "user",
        "content": "Hello from AWS Bedrock."
      }
    ]
  }'
```

</Step>
</Steps>

## Notes

- available models depend on Bedrock region and enabled access
- model availability can differ between AWS regions
- provider-specific quotas still apply

Browse compatible models on the [Models page](https://kiwillm.in/models?provider=aws-bedrock).
