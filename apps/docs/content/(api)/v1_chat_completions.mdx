# Chat Completions API

This is the main OpenAI-compatible endpoint for text generation in KiwiLLM.

<Callout type="info">
	Use this when you want the easiest drop-in migration path from the OpenAI API.
	Hosted requests go to <code>https://api.kiwillm.in/v1/chat/completions</code>
	with <code>Authorization: Bearer $KIWILLM_API_KEY</code>.
</Callout>
