# KiwiLLM Docs

KiwiLLM gives you one API for 200+ models across major providers, plus the dashboarding and controls you need to run production AI traffic with KiwiLLM branding, routing, and visibility.

Use it to:

- Route requests to multiple LLM providers (OpenAI, Anthropic, Google AI Studio, and others)
- Manage project API keys and provider keys in one place
- Track requests, tokens, latency, and cost across all your usage
- Compare models and providers without rewriting your application code
- Launch quickly with KiwiLLM's hosted platform and managed dashboard

## What KiwiLLM Tracks

KiwiLLM gives you production visibility into every request:

- **Usage metrics**: Requests, tokens, and latency
- **Cost breakdown**: Spend by model, provider, project, and key
- **Routing visibility**: See which provider served each request
- **Operational insight**: Use the dashboard to debug, optimize, and compare

Everything is surfaced in the dashboard so you can make routing and cost decisions with real data instead of guesswork.

## Getting Started

The fastest way to start is to point your OpenAI-compatible client at the KiwiLLM API:

```bash
curl -X POST https://api.kiwillm.in/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -d '{
  "model": "gpt-4o",
  "messages": [
    {"role": "user", "content": "Hello, how are you?"}
  ]
}'
```

KiwiLLM is OpenAI-compatible, so most migrations are a base URL swap plus a new API key. Continue with the [Quickstart](/quick-start) to get set up.
