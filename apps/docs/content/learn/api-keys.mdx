The API Keys page is where you create, review, and manage the keys your apps use to authenticate with KiwiLLM.

<ThemedImage alt="API Keys" basePath="/learn/api-keys" />

## Creating a key

Click **Create API Key** and give the key a name that reflects its purpose, such as:

- production
- development
- CI
- staging

New hosted keys use the KiwiLLM prefix:

```text
kiwillm_...
```

## What the table shows

Each row typically includes:

- key name
- masked key preview
- status
- created date
- creator
- usage and usage limit
- IAM rules, if configured

## Common actions

From this page, you can usually:

- create a key
- rename a key
- disable or delete a key
- adjust limits
- review IAM restrictions

Delete behavior is generally safer than hard removal because platforms often preserve audit history even after a key is no longer usable.

## Best practices

- use separate keys for production and development
- avoid sharing one key across unrelated systems
- name keys clearly so logs stay readable
- remove unused keys instead of letting them accumulate
- add IAM rules when a key should be restricted to specific usage
