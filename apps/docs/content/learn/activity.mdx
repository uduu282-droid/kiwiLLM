The Activity page is the request-by-request log for your project. It is the best place to inspect what happened on an individual API call.

<ThemedImage alt="Activity Logs" basePath="/learn/activity" />

## What you can see

Each activity entry can show:

- request status
- model and provider used
- token usage
- duration
- cost
- cache status
- source metadata
- timestamp

## Useful filters

Use filters at the top of the page to narrow the log by:

- time range
- providers
- models
- completion reason
- metadata headers

## Request detail view

Opening a log entry gives you a more complete breakdown.

### Summary cards

Typical summary cards include:

- duration
- tokens
- throughput
- inference cost
- cache result

### Request metadata

The detail view helps answer questions like:

- which model was requested?
- which model actually served the request?
- which provider handled it?
- was the request streamed?
- did it use cache?

### Routing insight

For routed requests, the page can also show how KiwiLLM selected the provider and which alternatives were available.

## When to use this page

The Activity page is especially useful when you want to:

- debug a failed or slow request
- compare provider behavior
- inspect routing decisions
- verify usage and cost on one call
- trace what happened in production
