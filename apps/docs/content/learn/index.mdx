The KiwiLLM dashboard is where you manage usage, API keys, projects, billing, and organization settings. This section walks through the main screens so you can move around the platform confidently.

## Project pages

These pages are scoped to the currently selected project:

- [**Dashboard**](/learn/dashboard) — overview, usage summary, and quick actions
- [**Activity**](/learn/activity) — per-request logs and debug details
- [**Model Usage**](/learn/model-usage) — usage by model
- [**Usage & Metrics**](/learn/usage-metrics) — requests, errors, cache rate, and trends
- [**API Keys**](/learn/api-keys) — create and manage project API keys
- [**Preferences**](/learn/preferences) — project-level behavior and defaults

## Organization pages

These pages affect the wider organization:

- [**Provider Keys**](/learn/provider-keys) — connect your own provider accounts
- [**Billing**](/learn/billing) — credits, plans, and payment state
- [**Transactions**](/learn/transactions) — payment and credit history
- [**Policies**](/learn/policies) — data retention and related org-level rules
- [**Team**](/learn/team) — members and roles
- [**Org Preferences**](/learn/org-preferences) — organization settings
- [**Audit Logs**](/learn/audit-logs) — organization activity history
- [**Guardrails**](/learn/guardrails) — request safety rules
- [**Security Events**](/learn/security-events) — guardrail and security-related events
- [**Referrals**](/learn/referrals) — invite-based credit earning
