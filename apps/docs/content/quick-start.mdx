# Quickstart

KiwiLLM gives you one OpenAI-compatible endpoint for routing requests across models and providers. If you already use the OpenAI API, the migration is usually just:

- Change the base URL to `https://api.kiwillm.in/v1`
- Use a KiwiLLM API key instead of a provider key

> **TL;DR** — Point your requests to `https://api.kiwillm.in/v1`, send `Authorization: Bearer $KIWILLM_API_KEY`, and keep the rest of your payload shape the same. The hosted docs domain may still be `docs.llmgateway.io`, but the product and API shown here are KiwiLLM.

## 1 · Create an API key

1. Sign in at [app.kiwillm.in](https://app.kiwillm.in)
2. Open your project dashboard
3. Create an API key
4. Save it in your environment

```bash
export KIWILLM_API_KEY="kiwillm_xxxxxxxxxxxxxxxxx"
```

## 3 · Choose a model

KiwiLLM accepts either of these model formats:

- Short ID: `gpt-4o`
- Provider-qualified ID: `openai/gpt-4o`

Browse the full catalog on the [Models page](https://kiwillm.in/models).

## 4 · What to do next

- Read the API reference for [`/v1/chat/completions`](/v1_chat_completions)
- Browse available models at [kiwillm.in/models](https://kiwillm.in/models)
- Manage keys and usage in the [dashboard](https://app.kiwillm.in/dashboard)
- Explore integrations, guides, and references in the docs navigation
