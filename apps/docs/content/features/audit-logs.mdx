# Audit Logs

Audit logs give organization owners and admins a chronological record of important account activity.

This is useful for:

- security reviews
- team management visibility
- billing and access investigations
- compliance-oriented change tracking

## Typical events

KiwiLLM can record events such as:

- organization updates
- project creation and deletion
- team membership changes
- API key creation, deletion, and status changes
- provider key changes
- billing-related events

## What each entry contains

Audit log records typically include:

- timestamp
- acting user
- action type
- resource type
- resource identifier
- supporting details about the change

## Access control

Audit logs are intended for privileged organization members only, typically owners and admins.

## Retention

Retention depends on your plan and deployment model. If you need longer-lived audit history, pair this feature with the appropriate hosted plan or self-hosted retention policy.

<Callout type="info">
	Audit logs are positioned as an advanced organizational feature. If you need
	longer retention or stricter governance, contact the KiwiLLM team about the
	right deployment and plan setup for your organization.
</Callout>
