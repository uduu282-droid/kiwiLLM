# Vision Support

KiwiLLM supports multimodal models that accept both text and image inputs in the same chat request.

You can provide images in two common ways:

- public HTTPS image URLs
- inline base64 data URLs

You can browse supported models on the [Models page](https://kiwillm.in/models?filters=1&vision=true).

## Basic image input

Use the standard OpenAI-style `content` array with text and image blocks:

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What do you see in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://example.com/image.jpg"
            }
          }
        ]
      }
    ]
  }'
```

## Base64 images

You can also send inline image data:

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "Describe this image."
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."
            }
          }
        ]
      }
    ]
  }'
```

## Multiple images

You can include more than one image in a single request:

```bash
curl -X POST "https://api.kiwillm.in/v1/chat/completions" \
  -H "Authorization: Bearer $KIWILLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "Compare these two images."
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://example.com/image-1.jpg"
            }
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://example.com/image-2.jpg"
            }
          }
        ]
      }
    ]
  }'
```

## Text-only requests still work

Vision-capable models still accept normal string content for text-only turns.

<Callout type="info">
	You only need the array format when you are actually mixing text and image
	inputs in the same message.
</Callout>

## Practical notes

- keep image URLs publicly accessible if you use remote files
- supported formats vary slightly by provider
- large images can increase latency and cost
- some providers have stricter size or count limits than others

If you are building generation workflows too, pair this page with [Image Generation](/features/image-generation).
